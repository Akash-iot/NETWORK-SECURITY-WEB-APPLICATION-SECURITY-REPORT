# NETWORK SECURITY & WEB APPLICATION SECURITY 🔐

A hands-on cybersecurity project covering **Web Application Security, Vulnerability Assessment, Firewall Configuration, and Network Traffic Analysis**.

This project focuses on identifying web application security weaknesses using OWASP ZAP, performing manual SQL Injection testing in WebGoat, configuring Windows Defender Firewall rules, and monitoring network traffic using Wireshark.

## 🔍 TASK 1 – WEB APPLICATION SECURITY

**Target:** OWASP WebGoat  
**Tool:** OWASP ZAP 2.17.0

Security findings:

- Cross-Site Request Forgery (CSRF)
- Missing Content Security Policy (CSP)
- HTTP Without HTTPS/TLS
- Missing Anti-Clickjacking Header
- Spring Actuator Information Disclosure
- Missing Cookie Security Attributes
- SQL Injection (Manual Testing)
- Potential Cross-Site Scripting (XSS)

## 🌐 TASK 2 – NETWORK SECURITY

**Tools:** Windows Defender Firewall & Wireshark

Activities performed:

- Configured Windows Firewall inbound rules.
- Managed TCP port 80 (HTTP) access.
- Studied common network security threats.
- Captured and analyzed DNS traffic.
- Monitored HTTP requests and responses.
- Identified suspicious TCP SYN port scanning activity.
- Analyzed network traffic using Wireshark display filters.
